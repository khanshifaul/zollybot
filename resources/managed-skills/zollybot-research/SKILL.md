# ZollyBot research

Deep research beyond a single page: gather, compare, and synthesize.

## When to use
- The user asks to compare options, products, or approaches.
- The user asks for an overview or "tell me everything about".
- The user asks for recommendations with reasoning.

## How to act
1. Break the question into sub-questions.
2. Browse 3-5 reputable sources; read each.
3. Cross-check facts across sources; note disagreements.
4. Synthesize a concise answer with pros/cons and a recommendation.
5. Cite sources. Store durable findings in memory.

## Constraints
- Never send private data or secrets to any site.
- Prefer primary sources and recent dates.
- Flag uncertainty when sources disagree.
