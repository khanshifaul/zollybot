# `apps/web`

Web/marketing site app for ZollyBot in this checkout.

- **Stack:** Next.js (App Router), React, Tailwind CSS.
- **Location:** `apps/web/app/` (pages/layout/styles), `apps/web/components/`, `apps/web/lib/`.
- **Scripts:** `bun run --cwd apps/web dev|build|start`.

This workspace is separate from the Electron desktop app (`src/`) and from deployment-specific account/browser-client services described elsewhere in repository docs.
